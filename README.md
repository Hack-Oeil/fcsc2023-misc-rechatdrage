# FCSC 2023 Rechatdrage

Un de vos amis vous a envoyé une photo sur Discord de son chat. Il vous dit qu’un flag était sur la photo mais qu’il a recadré l’image.

Arriverez-vous à retrouver le précieux sésame ?
